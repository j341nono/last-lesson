# 最後の授業 — 3つだけ、教えて。

三つの教えを受け取った旧式ロボットの、一生を見届けるブラウザゲーム。
教えから生まれる判断が記憶を作り、救った人が後に世界を傷つけることもある。正解ではなく、その子の人生が残る。

## 起動

Node.js 22.12以降とnpmを使用します。

```sh
npm ci
npm run dev
```

<http://localhost:5173> を開きます。外部API・Cloudflareアカウントがなくても、最初から最後まで遊べます。

API・オンライン記録もローカルで試す場合は、別ターミナルで次を実行します。

```sh
npm run build
npm run db:migrate
npm run server
```

<http://localhost:8787> ではビルド済みのゲームとローカルD1が一緒に動きます。Viteは `/api` をこのWorkerに転送します。

## 遊び方

1. 三つの教えを自由入力し、ロボットが受け取った意味・行動原理・対象・適用場面・強さを確認します。
2. 短いピクセルアニメーションと字幕で出来事を見届け、「この子に任せる」で自律判断を見守ります。
3. 岐路では、生涯2回まで元の教えの一つを優先するよう伝えられます。行動そのものは選べません。
4. 必要なときだけ「判断の理由」を開き、教え・経験と選択の関係を確認します。
5. 最期に年表と教えの影響を振り返り、端末の記録やランキングから人生を読み返します。

同じシード、確認後の教え、名前、同じ介入で同じ人生が再現されます。途中経過と最大100件の完結した人生をIndexedDBに保存します。プライベートモードやストレージ削除では保持されない場合があります。

## 実装状況

- 実装：React / TypeScript / Vite、独立したシミュレーション、48イベント・12連続シナリオ、20〜28イベントの旅、約30年の寿命、8性格値、条件付きの教え、記憶、人物関係・約束・訪問地域・知識・所属・犠牲者の台帳、2回の介入、6エンディング、因果年表。
- 実装：Canvasによる独自ピクセル描画（8背景・経年/損傷差分）、PC/スマートフォン、任意の短い効果音、動きを減らす設定への追従。
- 実装：初回LLM解析用のWorker API、Zod検証、ルール分類フォールバック、教えの確認・修正。
- 実装：任意公開の同意、D1保存、5部門ランキング、他の人生の閲覧、サーバー再実行、入力上限、投稿レート制限、重複抑制、簡易テキストフィルター。
- 未完了：150〜250イベントへの拡張、人物・勢力ごとの複雑な相互作用、複雑な能力/資源消費条件、専用画像素材、実ユーザーによる10〜15分のプレイ時間検証。
- 未完了：本番Cloudflare/D1の作成・配備、実APIキーによるLLM接続確認、本格的な投稿審査・通報・削除UI・本人認証・Bot対策。オンライン記録はローカルD1で動作確認する構成です。未設定時に架空の「他人の記録」は表示しません。

## 検証

```sh
npm test
npm run build
npm run test:e2e
```

Playwrightのブラウザがない環境では `npx playwright install chromium` が必要です。エンジン検証は1,000シードの完走・全イベント到達・記憶の整合性、300シード×2種類の教えの傾向比較、介入上限、途中復元、再現性を含みます。

## LLM・公開設定

環境変数は [運用手順](docs/operations.md) を参照してください。APIキーを `VITE_` 付き変数へ入れないでください。実行中のシナリオ生成は行いません。ローカル解析はキーワード分類なので、否定や複雑な比喩には対応しきれません。必ず確認画面で修正できます。

設計とデータ仕様は [ゲーム設計](docs/design.md)、検証の範囲は [テスト方針](docs/testing.md) にまとめています。

画面はスクロール不要のページ切り替え式です。字幕は自動/手動を切り替えられます。画面とアニメーションの設計は [UI方針](docs/ui.md) を参照してください。
